#  Videojuego basado en la saga Souls

Este es un videojuego que se inspira en la saga Souls, tanto en la tematica, la ambientacion y mecanicas principales 



---

##  Tecnologías principales

- Motor: Unity 

- Lenguajes: C#
 

---

##  Características

- Máquina de estados finita para controlar comportamientos enemigos
- Estados básicos: Idle, Patrol, Chase, Attack, Return
- Control de animaciones según estado actual
